## Version 1.0.19

- remaining duration of a cast now gets formatted based on these patterns:
  - above 30 seconds: `>30`, matching Platynator
  - between 10 and 30 seconds: just the number of seconds
  - below 10 seconds: 1 fraction, e.g. `3.4`

## New Feature: Custom Sound on Cast Start

- enable Play TTS/Sound on Cast Start feature via Edit Mode > Features dropdown
- select custom sound from the bottom dropdown Custom Sound

## New Feature: Target Marker Scale

- simple slider
